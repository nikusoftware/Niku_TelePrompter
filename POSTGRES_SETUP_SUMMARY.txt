## 🚀 Getting Started (Quick Steps)

### Windows Users
```powershell
# 1. Start PostgreSQL
.\setup-postgres.ps1 -Action up

# 2. Apply migrations
.\setup-postgres.ps1 -Action migrate

# 3. Access pgAdmin
.\setup-postgres.ps1 -Action connect

# 4. Open application at http://localhost
```

### Linux/macOS Users
```bash
# 1. Make script executable
chmod +x setup-postgres.sh

# 2. Start PostgreSQL
./setup-postgres.sh up

# 3. Apply migrations
./setup-postgres.sh migrate

# 4. Access pgAdmin
./setup-postgres.sh connect

# 5. Open application
```

### Manual Setup
```bash
# Start only
docker-compose -f docker-compose.postgres.yml up -d

# Apply migrations
cd "Niku Telepromter/Niku_Telepromter.Server"
dotnet ef database update
```

## 🔐 Security Notes

### Development Environment
- Default passwords are for local development only
- Database only accessible on localhost
- SSL/TLS not required for local connections

### Production Deployment
- Change all default passwords
- Use strong, unique passwords (min 16 characters)
- Enable SSL/TLS connections
- Restrict network access via firewall
- Use separate application user with limited permissions
- Enable audit logging
- Regular backups with encryption

### Connection String Examples

**Development**
```
Host=localhost;Port=5432;Database=niku_telepromter;Username=postgres;Password=your_password
```

**Production**
```
Host=db.example.com;Port=5432;Database=niku_telepromter;Username=niku_app;Password=SecurePassword123!;SSL Mode=Require;Trust Server Certificate=false
```

## 🐛 Troubleshooting

### PostgreSQL Won't Start
1. Check if port 5432 is in use: `netstat -tuln | grep 5432`
2. Remove old container: `docker rm niku_telepromter_postgres`
3. Remove old volume: `docker volume rm docker_postgres_data`
4. Start fresh: `docker-compose -f docker-compose.postgres.yml up -d`

### Migrations Fail
1. Verify Entity Framework is installed: `dotnet tool list -g | grep ef`
2. Check connection string in appsettings.json
3. Ensure PostgreSQL is running and accessible
4. Run with verbose output: `dotnet ef database update --verbose`

### pgAdmin Can't Connect
1. Verify both containers are running: `docker-compose -f docker-compose.postgres.yml ps`
2. Check network: `docker network inspect niku_network`
3. Restart services: `docker-compose -f docker-compose.postgres.yml restart`

### Can't Connect from Application
1. Check connection string format
2. Verify database exists: `psql -h localhost -U postgres -l`
3. Test connection: `psql -h localhost -U postgres -d niku_telepromter`
4. Check firewall rules if remote server
